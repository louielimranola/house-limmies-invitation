# House Limmies — An Invitation

A Game of Thrones / House of the Dragon–themed website that opens with a short
in-world story (House Limmies of the North vs. House Jalandoni of the South),
then poses one question: will you break bread with me?

## Structure

- `index.html` — story intro (pop-up/sequence) → main invitation page
- `assets/css/` — styles
- `assets/js/` — interaction logic (story sequence, yes/no handling, dragon animation)
- `assets/img/` — original artwork/assets (no copyrighted HBO material)

## Status

Work in progress — private project, not a portfolio piece.

## Running locally

Open `index.html` in a browser, or serve the folder with any static server, e.g.:

```bash
python3 -m http.server 8000
```
